# Code of Conduct

DeviceDeck adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in issues, pull requests and discussions is expected to follow it.

To report unacceptable behavior, contact the maintainer privately through their GitHub profile ([@biggersun](https://github.com/biggersun)). Do not use public issues for conduct reports. Reports are handled confidentially, and the maintainer will act according to the Covenant's enforcement guidelines.
